# Portfolio - Racha : Business Intelligence Analyst
Ce dépôt contient l'ensemble des livrables réalisés dans le cadre du **projet Aéroworld**, pour le client **Data ESN**.

## Objectif du projet
Ce projet a pour but de démontrer ma capacité à **structurer, piloter et valoriser un projet Data Analyst**, de la phase de cadrage jusqu’à la création de livrables Power BI et d’une documentation complète. Je suis ravie de pouvoir démontrer ma motivations et les compétences acquises via ce dernier.
